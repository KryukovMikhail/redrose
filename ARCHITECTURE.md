# Технический стек и устройство

«Red Rose» — статический сайт без сервера и сборки: одна HTML-страница с игрой от первого лица, сервис-воркер для офлайна и манифест для установки как приложения. Всё, от лабиринта до текстур и звуков, генерируется кодом прямо в браузере. Картинок, звуковых файлов и библиотек нет.

## Коротко

| Слой | Что используется |
|---|---|
| Разметка и логика | HTML5 + чистый JavaScript (ES2020+), без фреймворков и библиотек |
| Стили | CSS в `<style>` внутри `index.html`: токены цветов на `:root`, `env(safe-area-inset-*)` для вырезов экрана |
| Графика | Canvas 2D. Собственный рейкастер (как в Wolfenstein 3D) рисует кадр попиксельно в `ImageData` через `Uint32Array` |
| Текстуры и спрайты | Генерируются кодом при запуске: процедурные текстуры 64×64, спрайты 32×32 рисуются на скрытом canvas |
| Шрифты | Google Fonts: UnifrakturMaguntia (логотип), Kurale (заголовки), Old Standard TT (текст), Marck Script (записки); у каждого есть запасной системный шрифт |
| Звук | Web Audio API: весь звук и музыка синтезируются осцилляторами и шумом, есть эхо через линию задержки и панорама `StereoPannerNode` (звук слева, справа, глуше сзади). Три шины громкости: звуки, фоновый гул, музыка |
| Ввод | Клавиатура, мышь с Pointer Lock, сенсорный экран (джойстик слева или справа, обзор на другой половине), геймпад через Gamepad API |
| Вибрация | Vibration API на Android, отдача геймпада через `vibrationActuator`; на iPhone обходной приём через `<input type="checkbox" switch>` (iOS 18+) |
| Хранилище | `localStorage` на устройстве игрока, три независимых профиля игроков; перенос между устройствами кодом (gzip через `CompressionStream` + base64) или JSON-файлом. Сервера нет |
| Офлайн и установка | Service Worker + Web App Manifest (PWA), полноэкранный режим через Fullscreen API |
| Хостинг | GitHub Pages: https://kryukovmikhail.github.io/redrose/ |
| Чего нет | Сборки, бэкенда, базы данных, аналитики, внешних скриптов |

## Устройство `index.html`

Скрипт один, разделён комментариями-заголовками `/* ===== … ===== */`. Порядок частей:

1. **Константы, хеш и ГПСЧ.** `BUILD`, `FINAL`, детерминированный хеш `h32(x, y, salt)` от зерна этажа и генератор случайных чисел `rng` (mulberry32). Зерно этажа выводится из зерна забега: `floorSeed(base, floor)`.
2. **Текстуры и темы этажей.** Процедурные текстуры (кирпич, гобелены, черепа оссуария, вода, корни, книжные шкафы, витражи, очаги и др.) и массив `THEMES` с семью темами. Этажи I–VIII — Покои графа, Темницы, Затопленные склепы, Корни (дважды); с IX этажа `themeFor()` добавляет Библиотеку графа, Часовню, Кухни и погреба и чередует их со старыми. Тема задаёт текстуры, оттенок света, частоту предметов, своего обитателя и особые правила.
3. **Бесконечный лабиринт.** Мир разбит на чанки 16×16 тайлов. Каждый чанк строится из зерна `h32(cx, cy)`:
   - рекурсивный бэктрекинг по сетке 8×8;
   - немного петель;
   - иногда зал с колоннами;
   - проходы в соседние чанки, которые определяются хешем общей границы;
   - запертые решётки;
   - предметы в тупиках и ниши.

   Вернувшись назад, игрок видит те же коридоры. Далёкие чанки выгружаются из памяти, а изменения (открытые решётки, заросли корней, сдвинутые шкафы библиотеки, метки мелом) хранятся отдельно и накладываются при повторной генерации.
4. **Рендер.** Пол и потолок рисуются построчно, стены — по одному лучу на столбец (DDA). Спрайты сортируются по глубине и отсекаются по Z-буферу. Свет складывается из факела (радиус зависит от масла), до четырёх точечных источников рядом (свечи, маячки, огонь бомб, фонарь Тюремщика) и оттенка темы. Разрешение кадра подбирается под экран (~64–110 тыс. пикселей) и растягивается без сглаживания.
5. **Мир и механики.** Мел (маски символов накладываются на текстуру стены), ниши-укрытия, ремесло (4 рецепта), использование предметов, бомбы и огонь, внезапная тьма, страх, записки узников, дары Розы.
6. **Существа.**
   - **Тень** ходит по полю расстояний: это BFS от игрока по окну 45×45 тайлов, оно пересчитывается каждые 0,3 с. В темноте Тень охотится, при свете держится у его края, сквозь решётки проходит. С началом внезапной тьмы она подкрадывается на 7–11 шагов, вне прямой видимости, так что каждый сквозняк — настоящая угроза.
   - **Тюремщик** (темницы) видит игрока по лучу прямой видимости, сквозь решётки проходить не может.
   - **Утопленник** (склепы) слеп и идёт на шум. Радиус шума зависит от шага, тихого шага, бомб, решёток и мела.
   - **Корни** на своих этажах затягивают коридоры за спиной (тайл 6), их можно прожечь факелом. Заросли увядают через 90 с (на финале через 60 с), одновременно их не больше 70 (на финале 40), поэтому вернуться за шипами всегда можно.
   - **Библиотека:** раз в 16–28 с шкаф рядом сдвигается. Одна стенка между клетками открывается, другая закрывается, но только если обход в ширину подтверждает, что две стороны остаются связаны. Лабиринт меняется, но не рвётся.
   - **Часовня:** алтари (в залах и тупиках) — безопасный свет; рядом с ними быстро уходит страх, а Тень в часовне медленнее.
   - **Настенные факелы** (тайл 7, около 2% стен): упрись в погасший факел, и он загорится. Постоянный свет, который Тень не переступает.
   - **Тайники** (тайл 8): примерно в 9% пустых тупиков единственный проход заложен треснувшей кладкой. Упрись в неё, чтобы разбить; внутри сундук с редкими предметами. Связность лабиринта не меняется, потому что закрывается только тупик.
   - **Кухни:** масла втрое меньше, воска и фитилей втрое больше; очаги (тайл 3) светят и один раз подпаливают факел.
7. **Музыка и субтитры.** Генеративная музыка по теме этажа (`MUSIC`: лад, тембр, длительность нот, паузы; в Часовне — аккорды органа), затихает, когда Тень рядом. Звуковые субтитры (`cap()`) показывают у края экрана подписи к звукам с направлением: шёпот, шорох, ключи, плеск, звон Розы и т. д.
8. **Интерфейс.** HUD, мини-карта (разведанные клетки), компас к Розе, Сердцу или ближайшему шипу, экраны меню, настроек, испытаний, ремесла, записок, спуска, концовок. Подсказки обучения показываются по событиям один раз (очередь `tip()`), текст зависит от последнего способа ввода: клавиатура, касание или геймпад.
9. **Платформа.** Опрос геймпада в каждом кадре (стики, кнопки, навигация по меню с фокусом), полноэкранный режим, регистрация сервис-воркера и плашка обновления, вибрация, Wake Lock, главный цикл `requestAnimationFrame`.

### Объём контента (R001.008)

- 7 тем этажей: четыре на I–VIII, ещё три с IX этажа; сложность растёт с глубиной
- Финал на VIII этаже: три Шипа Розы и Сердце замка; при всех прочитанных записках — истинная концовка с выбором из двух финалов
- 12 даров Розы, выбор одного из трёх между этажами
- 8 испытаний; каждое открывает дар, который можно взять в начале забега
- 4 рецепта ремесла: ключ, огненная бомба, запасной факел, свеча-маячок
- 20 записок узников с сюжетом
- Существа и правила: Тень, Тюремщик, Утопленник, зарастающие корни, сдвигающиеся шкафы, алтари, очаги
- Подсказки обучения, настенные факелы, тайники с сундуками
- Музыка для каждой из 7 тем, звуковые субтитры
- Летопись 20 последних забегов и карточка итога (PNG 1080×1350 через canvas; «Поделиться» через Web Share API с файлом, иначе сохранение)

## Данные игрока

| Ключ | Где | Что хранит |
|---|---|---|
| `redrose_profile` | `localStorage` | Номер текущего игрока (0–2) |
| `redrose_save_v1` | `localStorage` | Текущий забег: зерно, этаж, позиция, масло, инвентарь, дары, собранные предметы, открытые решётки, заросли, сдвинутые шкафы, погасшие очаги, метки мелом, маячки, шипы, счётчики для испытаний. Сохраняется каждые 5 с и при ключевых событиях; после проигрыша удаляется |
| `redrose_meta_v1` | `localStorage` | Между забегами (у игроков 2 и 3 ключи с суффиксом `_p1`, `_p2`): летопись забегов, прочитанные записки, рекорд глубины, концовки, пройденные испытания, показанные подсказки и настройки (`set`: чувствительность, инверсия, громкость звуков и фона, качество, сторона джойстика, вибрация, подсказки) |
| `redrose_updated` | `sessionStorage` | Флаг «игра только что обновилась» для сообщения в меню |

Сохранение игроков 2 и 3 тоже хранится под ключами с суффиксом `_p1` и `_p2`. Код переноса начинается с `RR1:`, внутри сжатый JSON `{ meta, save }`; импорт показывает, что в коде, и заменяет прогресс только после второго подтверждения. Формат сохранения версионирован (`v: 2`); сохранения старого формата читаются и переводятся автоматически. Если хранилище недоступно (приватный режим), игра работает, но без сохранения.

## PWA и офлайн

- `manifest.webmanifest`: `display: fullscreen`, `start_url: ./`, тёмные цвета темы, обычная и maskable-иконки.
- `sw.js`, стратегии кэша:
  - **страница** (`navigate`): сначала сеть с `cache: no-cache`, при отсутствии сети — копия из кэша. С интернетом игрок всегда получает свежую версию;
  - **остальное** (иконки, шрифты Google): сначала кэш, обновление в фоне.
- Кэш называется `redrose-<BUILD>`. Новый сервис-воркер при установке скачивает файлы с `cache: reload` и ждёт. Страница узнаёт его версию через `MessageChannel` и показывает плашку «Вышла новая версия · Обновить». По нажатию воркер получает `skipWaiting`, страница перезагружается, старые кэши удаляются в `activate`.
- Проверка обновлений идёт при запуске, при возврате приложения из фона (`visibilitychange`) и каждые 15 минут.
- Сервис-воркер регистрируется только в защищённом контексте и не внутри iframe.

## Версии и выпуск

- Номер сборки — константа `BUILD` в `index.html` (формат `R001.0NN`), показывается вверху меню.
- При каждом релизе поднимается минорная версия, и `VERSION` в `sw.js` меняется на `redrose-<BUILD>`. Без смены `VERSION` установленные приложения не покажут плашку обновления.
- Выпуск — коммит в ветку `main`; GitHub Pages публикует его за 1–2 минуты.

## Проверка

- Синтаксис скрипта: `node --check` по содержимому `<script>`.
- Связность лабиринта: обход в ширину от старта по квадрату 8×8 чанков для каждой темы. Все клетки сетки должны быть достижимы.
- Playwright (headless Chromium, в том числе эмуляция телефона): настройки, подсказки, испытания и дар на старте, новые темы IX–XI (сдвиг шкафов, алтари, очаги), истинная концовка, геймпад (подменённый `navigator.getGamepads`: ход, обзор, пауза, навигация по меню), старт игры, ремесло, мел, бомба, маячок, Тень, внезапная тьма, ниши, спуск через все темы, дары, Тюремщик, Утопленник и тихий шаг, рост и прожигание корней, шипы, Сердце, концовка, полноэкранный режим. Сценарий обновления проверяется на локальном сервере: подмена сборки → плашка → «Обновить» → новая версия. Плюс скриншоты и замер FPS.

## Баланс

Бот-тестировщик (Playwright, ускоренное время, без отрисовки) проходит этажи: строит путь обходом в ширину к лепесткам, шипам и выходу, собирает предметы, мастерит, бросает бомбы, прячется, крадётся у Утопленника. Метрики по теме этажа: время, касания Тени, поимки, число и длительность тьмы, расход масла, минимум огня, гибели и застревания.

Последний прогон перед R001.008: 6 забегов по 14 этажей, без гибелей и застреваний. Среднее время этажа — 2,5–5 минут, касание Тени — раз в 4–6 этажей при идеальной игре, Склепы — самый трудный этаж (до 2 поимок, минимум огня 5%).

## Поддержка браузеров

- Целевые: Chrome и Safari на телефонах (Android, iOS), Chrome, Edge, Firefox, Safari на компьютере.
- Нет `StereoPannerNode` — звук без панорамы.
- Нет Fullscreen API (Safari на iPhone) — кнопка показывает подсказку «Поделиться → На экран „Домой“». Запуск с иконки идёт без панелей браузера.
- Нет Vibration API — вибрация просто не срабатывает.
- Нет Pointer Lock — обзор мышью по зажатой кнопке.
- Геймпад работает в браузерах со стандартной раскладкой Gamepad API (Xbox, PlayStation и совместимые); без `vibrationActuator` — без отдачи.
- Нет Service Worker или страница открыта во встроенном окне — игра работает онлайн, без офлайна и плашки обновлений.
- Звук на iOS запускается по первому касанию и с `navigator.audioSession.type = 'playback'`, чтобы работать при беззвучном режиме.
