# Red Rose

Мрачная игра от первого лица: бесконечный лабиринт средневекового замка Розенхолл. Собери пять лепестков Красной Розы, пока горит факел, и спускайся всё глубже, туда, где бьётся Сердце замка. В темноте бродит Тень.

**Играть:** https://kryukovmikhail.github.io/redrose/

Игра работает на компьютере и телефоне. Её можно установить как приложение: на Android — кнопкой «Установить» в меню, на iPhone — через «Поделиться → На экран „Домой“». Установленная игра работает без интернета и сама предлагает обновиться, когда выходит новая версия.

Технический стек и устройство игры описаны в [ARCHITECTURE.md](ARCHITECTURE.md).

## Что есть в игре

- Бесконечный лабиринт, который генерируется по мере движения
- Факел, масло и внезапная тьма от ледяного сквозняка
- Тень, которая охотится в темноте и боится света
- Этажи: Покои графа, Темницы, Затопленные склепы, Корни; на каждом свои правила и свой обитатель
- Ниши-укрытия, метки мелом на стенах, звук с направлением
- Ремесло: ключи от решёток, огненные бомбы, запасные факелы, свечи-маячки
- Дары Розы: после каждого этажа выбираешь одну способность из трёх
- 20 записок прежних узников, которые рассказывают историю замка
- Финал на VIII этаже, а после него бесконечный спуск

## Управление

| | Компьютер | Телефон |
|---|---|---|
| Идти | WASD | левый палец |
| Тихий шаг | Shift | лёгкое касание джойстика |
| Оглядываться | мышь, R / F — вверх и вниз | правый палец |
| Ремесло | C | кнопка «Ремесло» |
| Спрятаться в нише | H | кнопка «Спрятаться» |
| Мел | 1–4 | кнопка «Мел» |
| Предметы | O масло, B бомба, V свеча, T факел | кнопки справа внизу |
| Карта / пауза | M / Esc | кнопки вверху |

## Версии

- **R001.001** — бесконечный лабиринт, факел, лепестки и выход
- **R001.002** — Тень, ключи и решётки, внезапная тьма, взгляд вверх и вниз
- **R001.003** — этажи, мел, звук с направлением, ниши, ремесло, записки, вибрация, PWA
- **R001.004** — полноэкранный режим на телефоне
- **R001.005** — плашка «Доступна новая версия»
- **R001.006** — дары Розы, Тюремщик, Утопленник и тихий шаг, зарастающие корни, финал с Сердцем замка
